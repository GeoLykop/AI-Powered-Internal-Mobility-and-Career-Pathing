# AI-Powered-Internal-Mobility-and-Career-Pathing
CCS3900 Individual Project: An AI-powered web app for internal mobility and career pathing, using RAG and recommendation algorithms to map employee skills to internal roles.


# Overview:

In this repository I will store and showcase my code for my 3rd year as an Undergraduate Student for my Individual Project. My goals for this project is to develop a web application that allows employees to discover internal career opportunities within their chosen Organization, acknowledge and adapt to their skills in order for them to develop the necessary roles and unlock their hidden potential.
